# Employee Management System

A modern Employee Management System developed using Spring Boot as part of a hands-on DevSecOps learning journey.

---

## Project Overview

This application demonstrates the development of a secure enterprise-style web application using Spring Boot. The project is being enhanced step by step while simultaneously building a complete DevSecOps CI/CD pipeline.

---

## Features

- Employee Management (CRUD)
- Department Management
- Resume Upload & Download
- Search Employees
- Reports Dashboard
- Department Statistics
- CSV Export
- Spring Security Authentication
- BCrypt Password Encryption
- Responsive User Interface using Thymeleaf
